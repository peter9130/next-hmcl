## Introduction

Next HMCL is an independently maintained third-party distribution based on the open-source HMCL project. It is a cross-platform Minecraft launcher supporting mod management, game customization, mod loader installation (Forge, NeoForge, Cleanroom, Fabric, Legacy Fabric, Quilt, LiteLoader, and OptiFine), modpack creation, UI customization, and more.

Next HMCL supports Windows, Linux, macOS, FreeBSD, and CPU architectures including x86, ARM, RISC-V, MIPS, and LoongArch. See the [platform support table](PLATFORM.md) for actual platform and game-version coverage.

> **NOT AN OFFICIAL MINECRAFT PRODUCT. NOT APPROVED BY OR ASSOCIATED WITH MOJANG OR MICROSOFT.**
>
> Next HMCL is not an official HMCL release. It is maintained by 大量比比 (peter9130).

## Guide for Parents and Guardians

- This repository provides a launcher and **does not include the Minecraft game itself**. Users must obtain and use the game and related content lawfully.
- Minors should use the launcher with the knowledge and appropriate supervision of a parent or guardian, especially when playing online, downloading mods or modpacks, uploading skins, or sharing logs.
- Mods, modpacks, servers, and player chat are primarily supplied by third parties and are not all reviewed by the maintainer. Third-party content may be unsuitable for some ages or present security risks.
- The launcher connects to HMCL update services, Microsoft, Mojang, mod platforms, or download mirrors for updates, game downloads, account login, and mod downloads. Those providers may process network addresses and request information under their own privacy policies.
- The launcher does not automatically upload crash reports. Before voluntarily sharing logs or screenshots, check and redact account names, access tokens, file paths, and other personal information.
- To report inappropriate content or request assistance, contact the maintainer through [GitHub Issues](https://github.com/peter9130/next-hmcl/issues) or [Telegram](https://t.me/next_hmcl). Never post passwords, access tokens, or other sensitive information publicly.

## Download

Download Next HMCL from this project's [GitHub Releases](https://github.com/peter9130/next-hmcl/releases). Windows is supplied as an `.exe`; macOS is supplied as a `.jar` requiring Java 17 or later.

## Contributing

HMCL is a community-driven open-source project, and everyone is welcome to contribute code or provide suggestions.

You can contribute to HMCL development in the following ways:

- Report bugs or request features by [creating an issue](https://github.com/HMCL-dev/HMCL/issues/new/choose) on GitHub.
- Contribute code by forking the repository on GitHub and [submitting a pull request](https://github.com/HMCL-dev/HMCL/compare).

Before contributing, please read the [Contributing Guide](./Contributing.md), which includes the following:

- [How to build and run HMCL from source](./Contributing.md#build-hmcl)
- [Adjusting HMCL behavior using debug options](./Contributing.md#debug-options)
